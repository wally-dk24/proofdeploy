### T1. CodeIgniter4: deleteBatch() SQL injection

**Bug candidates:** All GHSA advisories for the held-out repos, published 2026-07-01 up to the skill-freeze date, sorted by GHSA ID ascending. PLUS commits in those repos whose message starts with `fix(` and that have no advisory, in the same window, sorted by commit SHA ascending (so the held-out set has functional bugs too). The script outputs candidates in order; the reviewer judges eligibility in that order and takes the first 4 passing (backend-only, behavior-changing, HTTP/DB observable).

**Clean diff candidates:** Commits in the held-out repos whose message starts with `feat(` or `fix(`, touching backend source, in the rule 8 window (4–6 weeks before the freeze), sorted by SHA ascending. The reviewer checks eligibility the same way; take 4.

The script output is the held-out set. No human judgment in selection.

**Fallback for non-`fix(` repos:** Flask, FastAPI and Koa mostly don't use `fix(`-style commit prefixes. If the `fix(` pool comes out empty for a repo, fall back to commits whose message matches `^(fix|bug)` case-insensitive, or that are linked to an issue labeled `bug`. The reviewer judges eligibility the same way.
