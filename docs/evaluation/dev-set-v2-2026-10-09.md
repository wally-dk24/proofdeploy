### T1. CodeIgniter4: deleteBatch() SQL injection
- **Repo:** https://github.com/codeigniter4/CodeIgniter4 (PHP)
- **B:** `2477f08627fb02f69d69c1b0174937905c56e3bb` (2022-11-22)
- **Fix:** `f5e463b9a3e986389ce285963e51a7f1fab6559f` (2026-06-30)
- **Advisory:** GHSA-c9w5-rwh3-7pm9 (CVE-2026-63221), Critical
- **Shipped:** v4.7.4 (2026-07-07)
- **Behavior:** `deleteBatch()` with `where()` substituted bind values raw into DELETE SQL, ignoring the escape flag; fix uses `convertWhereBindsForBatch()` respecting `$this->db->escape()`.
- **Files:** `system/Database/BaseBuilder.php` (backend)
- **Eligibility:** Backend-only, behavior-changing, DB observable.
- **B verification:** B^→B diff introduces `deleteBatch()` with the vulnerable `str_replace(':' . $field . ':', $bind[0], ...)` pattern. Verified.
- **Date caveat:** Fix commit 2026-06-30, one day before mid-2026 line. Advisory and release 2026-07-07. Reviewer's call.

### T2. Fastify: Header schema validation bypass
- **Repo:** https://github.com/fastify/fastify (TS/Node)
- **B:** `746e307cc4b6fa7cbccc0a590d93844afd7bf548` (2018-03-01)
- **Fix:** `179619c8e99d54924309b9933402151ef9af37e0` (2026-09-03)
- **Advisory:** GHSA-9q9j-q6p8-xq58 (CVE-2026-84428)
- **Behavior:** Mixed-case header names in schemas bypassed validation; fix normalizes recursively.
- **Files:** `lib/validation.js` (backend)
- **Eligibility:** Backend-only, behavior-changing, HTTP observable.
- **B verification:** B^→B adds partial header-name case-insensitivity (only top-level `properties`). The 2026 fix extends normalization to every schema subschema (nested, dependencies, etc.). The B diff introduces the incomplete behavior the fix completes.

### T3. Fastify: Auth bypass via malformed URLs
